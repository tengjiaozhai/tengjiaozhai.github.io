# 学习方法的两条轴

## 问题

新开的学习域目前只有两篇外部文章，一篇讲「怎么把材料变成理解」（[[wiki/concepts/领域速通]]），一篇讲「怎么把经历讲出去」（[[wiki/concepts/STAR法则]]）。如果它们只是两篇互不相干的剪藏，这个域就不成立 —— 一页一主题、彼此不链，价值低于三页互相链接的不完整记录。

所以先回答一个问题：**这两件事是不是同一条轴的两端？**

## 对比

| 维度 | 领域速通（输入侧） | STAR法则（输出侧） |
|---|---|---|
| 要解决的问题 | 陌生领域怎么在几十小时内变成能对话的地图 | 一段经历怎么讲得让别人能判断你会不会做 |
| 先定什么 | 三个槽：骨架 / 边界 / 检验 | 五个槽：情境 / 任务 / 行动 / 结果 / 收获，各带句数配额 |
| 内容从哪来 | 多来源素材（6 本书 + 15 篇论文 + 讲义） | 真实经历 + JD 关键词 + 独特价值 |
| 质量由谁判 | 自己（自测题答错就追问） | 对方（面试官追问还站得住吗） |
| 反什么 | 反对「帮我总结一下」式输入 | 反对背稿、反对流水账 |
| 失效形态 | 拿到地图没有能力；分歧点被幻觉污染 | 把空话结构化；结构替代不了深度 |

## 我的结论

**1. 共同形状：先定结构，再填内容。** 三问法先钉死「骨架 / 边界 / 检验」三个槽，再让模型往里填；STAR 先钉死五段和句数配额，再把经历装进去。两篇都不相信「内容堆得够多就会有结构」—— 结构是前置约束，不是事后总结的产物。

**2. 共同质量标准：别人能不能检验。** 第三个问题要的不是「考我」，是「能区分真懂与只背了知识点的人」——它把「理解」变成可判定的题。STAR 的结果与收获段要的不是「我很努力」，是让面试官能判定你会不会做这件事。两篇都在解同一个问题：**怎么把主观的「我会」转成可被第三方核对的证据**。

**3. 差别在检验者的位置上，这决定了两种不同的设计。** 自己检验时，机制是「答错能追问」（反馈回路短、可以无数次重来）；他人检验时，机制是「追问还站得住」（反馈回路长、只有一次机会）。所以输入侧重点是**题目的区分度**，输出侧重点是**证据的具体度**。

**4. 两篇还共享一个否定式判断：输入量不是变量。** 「一学期和 48 小时的差别不在内容量」与「目标不是死记硬背、而是建立可调整的基础」是同一句话的两面 —— 都否认「多读多背」本身产生能力。这一条是本域目前唯一能算判断的东西，其余都是方法描述。

## 适用范围

- 学一个新领域前：先用三问出地图，再决定读哪几份材料（避免从导论第一页开始）。
- 准备面试 / 述职 / 项目复盘：用 STAR 的五段与配额约束内容，先删再补。
- **本仓自己**：写 wiki 页也是这个形状 —— 先定模板字段（一句话定义 / 判断 / 机制 / 实例 / 边界 / 待澄清 / 证据），再往里填。字段缺了的页，内容会滑成流水账。这条是本仓既有实践与两篇外部方法的交叉点，属**类比**，不是来源。

## 未定论的分歧

- **「结构优先」对技能型任务成立吗？** 两篇的素材都是知识型 / 表达型任务。游泳、谈判手感、写作语感这类任务，「先定结构」可能反而是干扰。本仓无证据。
- **48 小时不可验证。** 输入侧的唯一时间证据来自二手转述，且没有对照组。整个学习域目前**零条自测数据** —— 包括本仓自己一次都没试过。
- **缺第三条轴：迁移验证。** 两篇都没回答「学会了没有」在真实任务上怎么验证。领域速通的终点是「能和导师对话」，STAR 的终点是「拿到 offer」—— 都是间接指标，都可能被别的因素解释。
- **两篇的体裁不同却并列**：一篇是传播型转述（含营销段落），一篇是职业教练的教学文。把它们放进同一个域，依据是方法论的形状，不是可靠性 —— 可靠性两者都低（`unverified`）。
